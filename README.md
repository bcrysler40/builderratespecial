# Builder Rate Special – interactive map

Live: https://builderratespecial.com (www redirects; builderratespecial.vercel.app also works)

Static site deployed on Vercel (project `builderratespecial`). Southern Home Loans – Brandon Crysler.

- `index.html`, `listings/index.html` – map page
- `manifest.webmanifest`, `sw.js`, `icons/` – installable app ("4.99% Homes"). Bump `VERSION` in sw.js whenever the page changes.
- `vercel.json` – headers
